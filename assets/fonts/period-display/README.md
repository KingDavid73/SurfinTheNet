# Period display fonts

These local fonts are used sparingly on homemade Orbit pages. All three families
come from the official Google Fonts repository and are licensed under the SIL
Open Font License 1.1. The corresponding license text is stored beside each font.

- Audiowide: https://github.com/google/fonts/tree/main/ofl/audiowide
- Bungee Shade: https://github.com/google/fonts/tree/main/ofl/bungeeshade
- Silkscreen: https://github.com/google/fonts/tree/main/ofl/silkscreen
