# Phase-two newcomer and oddity sheets

These three retained source sheets were generated with built-in ImageGen:

- `newcomer-photo-sheet.png`: 25 cheap 1997-1999 consumer photographs in a
  5x5 grid, grouped into five consistent fictional newcomer identities.
- `fan-web-graphics-sheet.png`: 25 amateur MS Paint, clip-art, flatbed-scan,
  and fan-shrine graphics in a 5x5 grid.
- `oddity-evidence-sheet.png`: 36 deliberately inconclusive photographs,
  scans, clippings, and doodles in a 6x6 grid for six harmless theories.

The cropped in-game assets are in `assets/images/phase2-newcomers/` and
`assets/images/phase2-oddities/`.

Final prompt summaries:

1. Create an exact 5x5 contact sheet of period-plausible newcomer portraits,
   computer desks, cassette collections, printed URL binders, scanners, and
   first-computer photos. Use harsh flash, red-eye, grain, dust, color casts,
   awkward framing, and no real brands or modern technology.
2. Create an exact 5x5 contact sheet of homemade King Cal and Byte Barn fan
   ephemera, strange-page snapshots, generic early-web decorations, and crude
   personal-page emblems. Use 1997-1999 MS Paint, consumer image-editor,
   photocopy, clip-art, and low-color GIF aesthetics with no real brands.
3. Create an exact 6x6 sheet of weak evidence for a reversed game-console
   logo, humming curb, oversized porch cat, modem-attracted moth, lake
   “knocker,” and inconsistent mascot cap. Keep every result ambiguous,
   harmless, low-resolution, period-authentic, and mundanely explainable.
